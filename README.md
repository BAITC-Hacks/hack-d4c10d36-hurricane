# Репетиционные кейсы

В репозитории находятся два небольших скрипта на Node.js 18 без внешних
зависимостей и API-ключей.

## 1. Классификатор обращений

Небольшой скрипт разбирает пять обращений из `messages.txt`, определяет для
каждого категорию — `справка`, `жалоба` или `другое` — и печатает черновик
ответа на русском языке.

### Запуск

Требуется Node.js 18 или новее. Из корня репозитория выполните:

```bash
node classify_messages.js
```

Можно передать другой текстовый файл, в котором каждое обращение находится на
отдельной строке:

```bash
node classify_messages.js путь/к/messages.txt
```

### Что получилось

Скрипт относит информационные вопросы к категории `справка`, сообщения о
неисправностях и плохом качестве обслуживания — к категории `жалоба`, остальные
запросы — к категории `другое`. Для пяти обращений из задания результат такой:

1. справка о месте учёбы — `справка`;
2. очередь и холодная еда — `жалоба`;
3. запись на консультацию — `другое`;
4. пропавший Wi-Fi — `жалоба`;
5. гостевая парковка — `справка`.

Правила и шаблоны ответов находятся в `classify_messages.js`. Файл ввода читается
в UTF-8; пустые строки и необязательная нумерация вида `1.` или `1)` игнорируются.

## 2. Фильтр критичных событий

Скрипт читает восемь событий из `events.json`, оставляет только записи с уровнем
`critical`, печатает их и выводит итоговую строку с количеством.

### Запуск

```bash
node filter_events.js
```

При необходимости путь к другому JSON-файлу можно передать первым аргументом:

```bash
node filter_events.js путь/к/events.json
```

### Что получилось

Из восьми событий отобраны `disk 90%`, `payment failed` и `db timeout`.
Итоговая строка: `критичных 3`.
